1 · Authority and source ownership

1.1 · Core rule

CAD-L1-1.1.1

1.1.1 · Remember

A7 is the constellation catalogue; this CAD repository is the home for drawing templates, versioned models, client views and CAD-specific memory. Google Drive preserves original documents; GitHub versions source-safe data and Actions tests; Pages displays the verified result.

Memory cue: Own the drawing rules here, do not duplicate the entire A7 registry.

2 · Client-facing drawing navigation

2.1 · Core rule

CAD-L1-2.1.1

2.1.1 · Remember

01 Drawings: 2D/3D and selected location. 02 Quantity takeoff: measured objects with metres/feet. 04 Packages: WBS or site modules. 05 Sources: previous versions, code and original evidence. More: learning, codes, Memory Wall and historical editing links.

Memory cue: Show a client the drawing before showing database internals.

3 · Entity identity and relationships

3.1 · Core rule

CAD-L1-3.1.1

3.1.1 · Remember

Every object keeps the source ID, model key, type, host relation, provenance and source state. Client tables show a compact item name, dimensions and measures; technical records are available inside the clicked element detail.

Memory cue: Presentation can simplify without discarding PK/FK-style provenance or item relationships.

4 · Numbered architectural versions

4.1 · Core rule

CAD-L1-4.1.1

4.1.1 · Remember

Each numbered architectural version is a complete immutable edition. v3.7 is the current Ashok final architectural drawing. v3.6 and earlier files remain independently selectable and recoverable. Engineering calculations and sanitary discharge documents are separate disciplines.

Memory cue: Never stretch an older layout while implementing a new user-approved version.

5 · Module boundaries

5.1 · Core rule

CAD-L1-5.1.1

5.1.1 · Remember

CAD owns drawings and geometric measurement. Scheduling/Primavera owns Gantt, activity calendars and resources. Cost Estimation owns BOQ and rates. Packages and source records belong in their CAD chapters rather than the drawings canvas.

Memory cue: Link to the owning module instead of implementing its work inside CAD.

6 · QA, archive and publication

6.1 · Core rule

CAD-L1-6.1.1

6.1.1 · Remember

Local browser edit history and developer controls are outside the normal client website. Existing code and Git history preserve them. A new CAD release requires PR staging, shared browser checks, exact-SHA Pages publication, and live readback, without claiming unperformed tests.

Memory cue: The website is a view of a governed model—not an editing database.
