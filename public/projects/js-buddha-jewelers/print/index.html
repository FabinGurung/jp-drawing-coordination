Printing the received drawings on A4

Check the original sheet scale: All ten DXF paper-space layouts are set to 420 × 297 mm (A3). The original plot style is monochrome.ctb. Simply changing paper to A4 cannot preserve the same physical paper scale.

Option A: complete sheet and original title-block composition

  1. Open the original DWG and select the required Layout tab (1–7, A–C).
  2. Press Ctrl+P and choose DWG To PDF.pc3 or AutoCAD PDF.
  3. Choose ISO A4 landscape, Plot area Layout, and the original monochrome.ctb only when available.
  4. Use Fit to Paper / center, then Preview and verify all edges, text and title block. The physical content is reduced relative to A3. A standard A3→A4 proportional reduction is about 70.7%.
  5. Save as a new PDF; never overwrite the DWG or an approved source. In the PDF print dialog choose A4 landscape and Actual size if the PDF page is correctly A4.

Option B: close-up of one floor plan

  1. Open Model and enter ZOOM then Extents only to find the drawing.
  2. Press Ctrl+P, select ISO A4 landscape, What to plot → Window.
  3. Precisely select the intended floor-plan boundary and dimensions; exclude large unrelated site areas only if a cropped sheet is acceptable.
  4. Enable Center the plot and Fit to paper; Preview to check no text or linework is cut off.
  5. Save with an explicit close-up filename. This is a separate review crop and does not reproduce the whole original title block or retain an approved drawing scale.

Fidelity gate: Original A3 layout, fonts, blocks and true paper scale should be independently checked in native AutoCAD before calling any PDF approved or to scale. The unrelated owner/ward in the received title block must also be resolved.
